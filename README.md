# Verity AI Router

Локальный AI-роутер на FastAPI, который объединяет языковые модели, синтез и
распознавание речи под одним HTTP API. Провайдеры подключаются отдельными
модулями и обнаруживаются автоматически. Настройки читаются из `.env`,
Swagger доступен по адресу `/docs`.

Программа нужна, чтобы запускать почти всё сразу из одного файла (`main.py`) —
без отдельных серверов для чата, озвучки и распознавания речи. Так можно
спокойно играть в мод Verity. Так же чтобы использовать другие llm, tts, sst модели, которые не поддерживаются в моде.

## LLM

Чат через OpenAI-совместимый endpoint. Поддерживаются DeepSeek (облако) и
Ollama (локально), есть стриминг ответов. Провайдер выбирается по имени модели
в запросе, список моделей отдаёт `/v1/models`. Нужно использовать как локальную Ollama модель.

Основные пути: `POST /v1/chat/completions`, `GET /v1/models`, `GET /api/tags`.

## TTS

Синтез речи в WAV. Нужно использовать как локальную Kokoro модель. Два варианта:

- **Piper** — локальные голосовые модели из `src/verity_ai/data/tts`. 
- **Удалённый TTS** — внешний OpenAI-совместимый сервер, включается через
  `TTS_API_URL`.

Основные пути: `POST /v1/audio/speech`, `GET /v1/audio/voices`.

## STT

Локальное распознавание речи через faster-whisper. Модель загружается лениво
и скачивается при первом запросе в `src/verity_ai/data/stt`. Язык может
определяться автоматически. Нужно использовать как локальную SST модель.

Основные пути:

- `POST /v1/audio/transcriptions` — форматы `json`, `text`, `verbose_json`.
- `GET /v1/audio/transcriptions/models`.

Алиас `whisper-1` использует модель из `STT_MODEL`, также доступны `tiny`,
`base`, `small`, `medium`, `large-v3` и другие.

## Запуск

```bash
uv sync
uv run python scripts/create_env.py
uv run main.py
```

После запуска API доступен на `http://127.0.0.1:8880`, документация —
на `http://127.0.0.1:8880/docs`.
